# CERVAULT Support

## Public bugs and feature requests

Use GitHub Issues in this repository for public, sanitized bug reports and feature requests.

Do not post secrets, credentials, private repository content, customer information, billing identifiers, or confidential evidence.

## Private support

For security, privacy, account, or billing matters, use the private support route listed at:
https://cervault.marsci-diagnostics.com/support/

## Release questions

When reporting an installation or runtime problem, include the exact release version, operating system, architecture, and whether the artifact checksum matched `SHA256SUMS.txt`.
