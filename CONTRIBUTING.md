# Contributing to CERVAULT

This repository is the public distribution, documentation, and release surface for CERVAULT.

## Report a bug

Use the public bug-report issue form. Include:
- platform and architecture,
- CERVAULT version,
- expected behavior,
- actual behavior,
- minimal reproduction steps,
- sanitized logs or screenshots when useful.

Never post credentials, tokens, private repository contents, customer data, billing identifiers, or confidential evidence.

## Request a feature

Use the feature-request issue form and describe the governance problem, the agent/tool involved, the desired control, and why existing behavior is insufficient.

## Scope of public contributions

Good public contributions include:
- documentation corrections,
- reproducible public bug reports,
- release/install feedback,
- compatibility findings,
- governance use cases that do not expose private implementation details.

The confidential control-plane/runtime implementation is intentionally not published in this repository. Public contributions should not attempt to reconstruct or request private implementation details.

## Release verification

For public preview binaries, verify the downloaded asset against `SHA256SUMS.txt` from the matching GitHub release before use.
